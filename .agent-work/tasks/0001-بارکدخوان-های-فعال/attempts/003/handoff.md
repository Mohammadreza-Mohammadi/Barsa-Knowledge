# Handoff

وضعیت: نقشه آماده است، یک فرمان create روی `report`.

نقش بعدی: implementer.

**یک یافتهٔ کلیدی:** ستون «دوربین» روی فیلدی از نوع `command` می‌نشیند و اینکه
بارسا چنین ستونی را می‌پذیرد Unknown است (R-1). نوشته می‌شود چون کاربر خواست،
و در گیت apply-approval باید به چشم انسان برسد.

ترتیب خواندن: `task.md` → `plan.md` → `risks.md` → `tests.md`.
