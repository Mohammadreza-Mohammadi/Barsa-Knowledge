# 0001 — گزارش لیستی تازه روی BarcodeReader

یک `AiChangeBatch` با یک فرمان create روی `report`، والد `#BarcodeReader`.

برای مهندس بعدی دو نکته:

- موجودیت هدف یک گزارش با update عوض نمی‌شود (`entity` روی گزارش ReadOnly است).
  اگر این گزارش باید روی موجودیت دیگری برود، حذف و ساخت تازه است، نه patch.
- ستون دوم روی یک فیلد از نوع `command` است. اینکه بارسا چنین ستونی را
  می‌پذیرد در بستهٔ دانش Unknown است؛ اگر در عمل نادیده گرفته شد، این همان
  ریسک R-1 است، نه یک باگ در batch.
